# Stampdrill for Visual Studio Code

Syntax highlighting for Stampdrill `.stamp` files: request lines, headers,
directives, `{{ }}` interpolation, response scripts, test plans, load tests and
environments.

## Install

In VS Code:

```bash
code --install-extension StampDrill.stampdrill
```

Or from the [Marketplace page](https://marketplace.visualstudio.com/items?itemName=StampDrill.stampdrill).

Cursor, Windsurf and VSCodium don't carry Microsoft's marketplace, download
`stampdrill-<version>.vsix` from the
[latest release](https://github.com/stampdrill/stampdrill/releases/latest) and
install it directly:

```bash
code --install-extension stampdrill-1.4.0.vsix
```

The language is described at https://stampdrill.com/language/.
